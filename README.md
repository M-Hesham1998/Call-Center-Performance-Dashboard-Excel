# 📞 Call Center Performance Dashboard | Excel

## 📌 Project Overview
This project presents an interactive Excel dashboard designed to analyze call center performance and monitor key business metrics.

The dashboard provides an overview of revenue, call volume, customer base, representative performance, call duration, and customer ratings.

## 🎯 Project Objectives
- Monitor overall call center performance.
- Track revenue and call volume over time.
- Evaluate sales performance by representative.
- Analyze call distribution by day and call duration.
- Compare average customer ratings across representatives.
- Present key metrics in an interactive and easy-to-understand dashboard.

## 🛠️ Tools & Techniques
- Microsoft Excel
- Pivot Tables
- Charts & Data Visualization
- Interactive Filters
- KPI Cards
- Dashboard Design & Formatting

## 📊 Dashboard Features
- **Overview KPIs:** Revenue, Total Calls, Representatives, and Total Customers.
- **Monthly Analysis:** Track sales and revenue trends by month.
- **Representative Performance:** Compare sales and call volume across representatives.
- **Call Analysis:** Explore call distribution by day and duration.
- **Customer Ratings:** Compare average ratings across representatives.
- **Interactive Filtering:** Explore the dashboard using month and day filters.
